# Medical Image Processing — Final Project
## Author: Einar López Altamirano

End-to-end pipeline for a paired brain **PET/MR** study:

1. DICOM loading, header inspection and visualization
2. 3D rigid coregistration of the PET (input) to the MR (reference) using `itk-elastix`
3. Semi-automatic tumor segmentation on the MR using **nnInteractive**, evaluated against both a cross-modal PET-derived reference and a manual MR annotation

## How to run

Execute the notebooks **in order**. Each one writes the artifacts the next one needs into `data/processed/`.

### 1. `task1.ipynb` — DICOM loading and visualization

- Loads PET and MR with PyDicom; inspects relevant standard and vendor-private headers.
- Rearranges the flat `(1692, 256, 256)` PET pixel array into a 4D `(time, slice, y, x)` volume.
- Visualizes the last PET frame and the temporal average.
- Builds an animated GIF of the three median planes across the dynamic acquisition.
- **Exports** `data/processed/mean_pet.mha` and `data/processed/last_frame_pet.mha`.

### 2. `task2.ipynb` — 3D rigid coregistration

- Loads the MR with `itk.imread` and the PET artifacts from Task 1.
- Runs `itk.elastix_registration_method` with the `'rigid'` preset (Mattes mutual information, Euler 6-DOF transform, geometric-center initialization, 4-level multi-resolution pyramid).
- Validates the registration with an alpha-fusion overlay on the central slices.
- Builds the **rotating MIP GIF** (72 angles, three panels: MR / co-registered PET / alpha-fusion).
- **Exports** `data/processed/registration_transform.txt`.

### 3. `task3ac.ipynb` — Manual bounding box + assessment (local)

- Loads the MR, the PET last frame and the saved transform.
- Applies the transform to the PET last frame via `itk.transformix_filter` so it lands on the MR grid.
- Provides an **interactive bounding-box tool** (`ipywidgets` + `matplotlib RectangleSelector`) for picking the tumor's prompt box in MR voxel space.
- **Exports** `data/processed/mr.nii.gz` (the MR in NIfTI form, ready for Colab).
- After the AI mask returns from Colab, performs the **visual + numerical assessment**:
  - Visual overlays of the AI mask on the MR and PET.
  - A cross-modal PET-threshold reference (supplementary).
  - The primary evaluation against the **manual MR annotation** (see below).

### 4. `task3b.ipynb` — AI segmentation on Google Colab

- Upload `data/processed/mr.nii.gz` to a Colab session with GPU runtime.
- The notebook installs `nnInteractive` and pulls its checkpoint from the Hugging Face Hub.
- Runs `nnInteractiveInferenceSession` with the bounding box recorded in `task3ac.ipynb`.
- Saves the result as `tumor_mask.nii.gz`; download it back into `data/processed/`.

### 5. Manual MR annotation (external tool, required for Task 3C primary evaluation)

For the primary segmentation evaluation in `task3ac.ipynb`, a manual reference mask is drawn on the MR using **ITK-SNAP** (or **3D Slicer**):

1. Open `data/processed/mr.nii.gz`.
2. Use the polygon tool to outline the tumor on every fifth axial slice across the lesion (z ≈ 43–95).
3. Run **Tools → Interpolate Labels → Morphological** to fill the intermediate slices.
4. Save the segmentation as `data/processed/manual_mask.nii.gz`.

`task3ac.ipynb` then loads this file and computes Dice, IoU, precision, recall, volume comparison and centroid distance against the AI mask.

## Notes

- The interactive widgets in `task3ac.ipynb` require `%matplotlib widget` (provided by `ipympl`). If figures do not render, ensure `ipympl` is installed and the kernel has been restarted.
- The `'rigid'` parameter map in `task2.ipynb` sets `ResultImagePixelType` to `float32` so the resampled images are not quantized.
- All geometry is preserved as the volumes pass between PyDicom, ITK, NIfTI and back; the AI mask returned from Colab sits on exactly the same voxel grid as the MR.
